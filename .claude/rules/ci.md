# Continuous integration

GitHub Actions: `ci.yml` (jobs `changes`, `lint`, `test` on Linux and macOS (the tests, then `make smoke`), `race`, and the gate `Report Result`; Windows is not supported, see `PLT`), `security.yml` (govulncheck), Dependabot weekly. `release.yml` is run by hand for a release, a tag on a commit of `main` (see "Releasing" in `ROADMAP.md`); GoReleaser builds and publishes, pinned in the `Makefile` like the other tools, and `make release-check` tries it without publishing. Keep the gate's job name `Report Result`. Tool versions are pinned in the `Makefile`; do not use unpinned `@latest` tools.
