# Continuous integration

GitHub Actions: `ci.yml` (jobs `changes`, `lint` (which also checks the message catalogs), `test` on Linux and macOS (`make check-coverage`, the tests with the coverage floor, then `make smoke`), `race`, and the gate `Report Result`; Windows is not supported, see `PLT`), `security.yml` (govulncheck), Dependabot weekly. `release.yml` is run by hand for a release, a tag on a commit of `main` (see "Releasing" in `ROADMAP.md`); GoReleaser builds and publishes, and cosign signs the checksums keyless (`id-token: write`), both pinned in the `Makefile` like the other tools; publishing also commits the Homebrew cask to `MelancholyPurin/homebrew-tap` with the secret `HOMEBREW_TAP_TOKEN`; `make release-check` tries it without publishing or signing, and `make release-verify` checks a built release as a download would be checked. Keep the gate's job name `Report Result`. Tool versions are pinned in the `Makefile`; do not use unpinned `@latest` tools.

The repository settings (squash merge only, branches deleted after merge, `main` protected and requiring `Report Result`) are written down in `.github/scripts/protect-main.sh`; change them there and ask the maintainer to run it, never in the settings page alone. `make hooks` turns on the pre-push lint (`.githooks/pre-push`). The job `translations` (`make translations-check`) runs for every change and is part of `Report Result`.
