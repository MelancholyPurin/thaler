## v0.1.0 (2026-11-01)

The first release. Thaler is a local-first personal finance planner for one person: a terminal interface and a command line over a single SQLite file on your own machine. No server, no account, no bank sync.

### What it does

- A double-entry ledger: accounts (assets, liabilities), income and expense categories, and transactions made of postings that always balance. Amounts are whole minor units, never floats.
- Several currencies: a currency per account, a base currency, exchange rates, and net worth in the base currency.
- Importing bank exports: the Hamburger Sparkasse CSV (CAMT) and custom profiles for other banks in `config.toml`. Importing the same file twice adds nothing, rows are categorised by your rules, a dry run shows what would happen, and a whole import can be taken back. A row you entered by hand is claimed by its bank row, and the two halves of a transfer between your own accounts are paired.
- Transfers between your accounts, within one currency or across two.
- The interface (`thaler`): accounts and transactions with a detail pane, add, edit, delete and undo, fuzzy search, month navigation, an import popup, a transfer popup, categorising with rule creation, and a `?` key reference. Everything is also a command under `thaler cli`.
- Keeping your data safe: consistent backups, optionally encrypted with a passphrase (age); restoring from the interface or the command line, always keeping the database it replaced; a reminder when the last backup is old; pruning old backups, after asking; and a checked copy of the database before any upgrade changes it.

### What it does not do yet

No budgets, reports, recurring transactions or forecast; no Spanish or German; no creating or editing a transaction split over several categories; no server or web app. The Sparkasse import has been tried on one real export. Thaler runs on macOS and Linux (Intel and ARM), not on Windows.

### Upgrading

Any later release opens a database written by this one, after making a copy of it first. Going back to an older release is not supported: restore a backup instead. Until `1.0.0` commands, flags and config keys may change between releases, and the release notes will say so.

### Install

Download the archive for your system below, check it against `checksums.txt`, and unpack it. The README has the steps.
